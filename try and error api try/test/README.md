# 🧪 GST Onboarding Flow Test

## Overview

This test simulates a complete onboarding flow where:

1. **Chatbot collects** email and phone number from user
2. **User uploads** GST PDF certificate
3. **OCR extracts** company information from GST:
   - Legal Name
   - GSTIN
   - Address (line1, line2, city, state, pincode)
   - Directors/Partners names
   - Constitution type
4. **System auto-generates** random secure password
5. **Calls Cargo API** with all extracted data
6. **Stores vendor code** for subsequent KYC calls

## Prerequisites

1. **Server must be running:**
   ```bash
   npm start
   ```

2. **Internet connection** (to reach Cargo API at `qaapis2.delcaper.com`)

## Running the Test

### Option 1: Run directly
```bash
node test/test-gst-onboarding-flow.js
```

### Option 2: Add to package.json scripts
Add this to your `package.json`:
```json
{
  "scripts": {
    "test:gst": "node test/test-gst-onboarding-flow.js"
  }
}
```

Then run:
```bash
npm run test:gst
```

## Troubleshooting

### Error: ECONNREFUSED
```
💡 Make sure the server is running:
   npm start
```

### Error: 409 Conflict
```
⚠️ Email or mobile already exists
```
**Solution:** The test auto-generates unique email/phone each run. If you still get 409, the API might have rate limiting.

### Error: 400 Bad Request
Check that all required fields are present in the payload.

### Error: 500 Internal Server Error
The Cargo API might be down. Check API status.

## Customization

### Use Different GST Data
Edit the `MOCK_GST_OCR_DATA` object in `test-gst-onboarding-flow.js`:

```javascript
const MOCK_GST_OCR_DATA = {
  gstin: 'YOUR_GSTIN_HERE',
  legalName: 'YOUR_COMPANY_NAME',
  // ... other fields
};
```

### Change Password Generation
Modify the `generateRandomPassword()` function:

```javascript
function generateRandomPassword() {
  // Your custom logic
  return 'YourPassword123!';
}
```

### Add More Service Areas
Edit the `serviceAreas` array in the payload:

```javascript
serviceAreas: [
  {
    city: "Bangalore",
    state: "Karnataka",
    pincode: "560001",
    isActive: true
  }
]
```
